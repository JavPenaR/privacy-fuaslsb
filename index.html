Política de Privacidad

Entrenador FUAS

Última actualización: 05 de agosto de 2026

Esta Política de Privacidad explica cómo la aplicación Entrenador FUAS recopila, utiliza y protege la información de sus usuarios.

1. Información recopilada

La aplicación puede recopilar la siguiente información:

  • Nombre del usuario.
  • Dirección de correo electrónico.
  • Información básica de autenticación mediante Google Sign-In.
  • Datos ingresados voluntariamente para completar simulaciones o entrenamientos del FUAS.

2. Uso de la información

La información recopilada se utiliza únicamente para:

  • Permitir el acceso a la aplicación.
  • Personalizar la experiencia del usuario.
  • Guardar el progreso del entrenamiento.
  • Mejorar el funcionamiento de la aplicación.
  • Corregir errores y optimizar el servicio.

3. Información que NO recopilamos

Entrenador FUAS no recopila:

  • Información bancaria.
  • Contraseñas de otras plataformas.
  • Ubicación GPS.
  • Contactos del dispositivo.
  • Fotografías o archivos personales.

4. Compartición de información

No vendemos, comercializamos ni compartimos información personal con terceros.

Únicamente se utilizan servicios tecnológicos necesarios para el funcionamiento de la aplicación, tales como:

  • Google Sign-In.
  • Firebase (si corresponde).
  • Servicios de infraestructura necesarios para la operación.

5. Seguridad

Aplicamos medidas de seguridad razonables para proteger la información de los usuarios frente a accesos no autorizados, alteraciones o pérdidas.

6. Conservación de datos

Los datos se conservan únicamente durante el tiempo necesario para prestar el servicio o mientras el usuario mantenga una cuenta activa.

7. Derechos del usuario

El usuario puede solicitar:

  • Acceso a sus datos.
  • Corrección de información.
  • Eliminación de su cuenta.
  • Eliminación de sus datos personales.

8. Menores de edad

La aplicación está destinada a estudiantes y usuarios que deseen practicar el proceso de postulación al FUAS. Cuando corresponda, el uso deberá realizarse bajo la supervisión de un adulto responsable o institución educativa.

9. Cambios a esta política

Esta Política de Privacidad podrá actualizarse cuando existan modificaciones en la aplicación o en la normativa aplicable.
